# Support

Where to get help with **Hyperion** (the portable agents/skills kit).

## Adopters (using the kit in your product repo)

1. Read [GETTING-STARTED.md](./GETTING-STARTED.md) and the [common pitfalls](./.github/docs/troubleshooting/armadilhas-comuns.md) guide (EN: [common-pitfalls-en.md](./.github/docs/troubleshooting/common-pitfalls-en.md)).
2. Prefer chat in **your** repo: `/doctor`, `/setup`, or `/migrate`.
3. Still stuck? Open a [Question](https://github.com/MatheusFelipeCorrea/Hyperion/issues/new/choose) issue on this repository with:
   - IDE (Cursor / Claude Code / Copilot)
   - What you copied vs skipped (see README copy table)
   - Exact command or chat phrase
   - Error text or unexpected behavior

Do **not** paste secrets, PATs, or private product code into public issues.

## Contributors (changing Hyperion itself)

See [CONTRIBUTING.md](./CONTRIBUTING.md). Use **`good first issue`** / **`help wanted`** when looking for a task.

## Security

Do not open a public issue for vulnerabilities. Follow [SECURITY.md](./SECURITY.md).

## Maintainer

[@MatheusFelipeCorrea](https://github.com/MatheusFelipeCorrea) — prefer GitHub issues for product questions so others can find the answer later.
